# Source and publication provenance

Repository: mewhhaha/asslang. The ASABI implementation was restored from the
attached `asslang-asabi1.zip`; its original 96 Node tests passed before extension.
The source now adds causal observations, scans/transducers, bounded iteration,
prepared input leases, examples and additional validation.

The remote main read during this work was commit
`278903be98ab3bf50088fa79c374705e6c7ab3c7`, tree
`e90c51d70bd365668a322835a267fa897bf260fa`. It still contained the original kernel
plus two probe files, not the ASABI update previously described as published.
This delivery therefore includes both the saved ASABI work and the 0.2 extension.
Unrelated probe files and legacy measurements are preserved rather than removed.

The GitHub connector is used to build the complete tree, compare it with the local
source tree, and request a non-forced main update with the inspected main as parent.
An object-creation response alone is not evidence of branch publication. The
accompanying conversation reports the result of reading the branch back. Source
manifest hashes and recorded test/benchmark evidence identify the delivered files.
